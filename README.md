# 📊 Advertising Sales Prediction using Multiple Linear Regression

## 📌 Project Overview

This project predicts **product sales** based on advertising expenditure across three different media channels:

- 📺 TV
- 📻 Radio
- 📰 Newspaper

The objective is to analyze the relationship between advertising budgets and product sales using **Multiple Linear Regression**, a supervised machine learning algorithm.

---

## 🎯 Problem Statement

Businesses invest heavily in advertising, but determining which advertising channel contributes the most to sales is challenging.

This project aims to:

- Analyze advertising data.
- Identify the relationship between advertising expenditure and sales.
- Build a machine learning model to predict future sales.
- Provide business insights for better marketing decisions.

---

## 📂 Dataset

The dataset contains **200 observations** and **4 features**.

| Feature | Description |
|---------|-------------|
| TV | Advertising budget spent on TV |
| Radio | Advertising budget spent on Radio |
| Newspaper | Advertising budget spent on Newspaper |
| Sales | Product sales (Target Variable) |
